Welcome to **The Nexus Archive**. This is not your standard programming tutorial. It is a fully interactive, narrative-driven browser game designed to teach Data Science with Python through a gripping Sci-Fi Noir storyline. 

The city's central AI has been corrupted. As a rogue Data Detective, your only weapon is the ancient syntax: **PYTHON**.

---

## 🚀 Quick Start

No installation. No bundlers. No Python backend required.
1. Download or clone this repository.
2. Open **`index.html`** in any modern web browser.
3. *Jack into the matrix.*

---

## ✨ Features

### 📖 Plot-Driven Curriculum
* **Active Leads (Missions):** Progress through a linear storyline divided into Acts (The Streets, The Mainframe, The Core). You must decrypt each node using Python logic to unlock the next.
* **City Archives:** Permanently unlocked reference databanks covering fundamental Python concepts (Variables, Control Flow, Data Structures, Functions) to aid your investigation.
* **O.R.A.C.L.E. Assistant:** Built-in dialogue systems and hints that guide you through complex data science syntax.

### 🎨 Premium Cinematic UI
* **High-End Glassmorphism:** Heavy `backdrop-blur`, subtle borders, and deep shadows emulate a futuristic holographic detective dashboard.
* **Immersive Animations:** Powered by **GSAP** and **Lenis** for buttery-smooth scroll triggers, 3D hover effects, and cinematic fade-ins.
* **Fully Responsive:** Beautifully scales across mobile devices, tablets, desktop monitors, and ultra-wide TVs.

### 🛠️ Zero-Dependency Architecture
Built to be lightning-fast and universally accessible.
* **Frontend:** Pure HTML5 and Vanilla JavaScript.
* **Styling:** Tailwind CSS (via CDN) for rapid, responsive UI development.
* **Animations:** GSAP & Studio Freight Lenis.
* **Persistence:** Uses `localStorage` to save your clearance level and decrypted nodes offline.
